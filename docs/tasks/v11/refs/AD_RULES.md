**v10 update (founder, 2026-10-24, after v9):** reference = zeeuiux "making of a launch film" reel DeKoRsNgOPK (E:\reel_study\DeKoRsNgOPK, analysis REEL_DeKoRsNgOPK_clean_liquid_glass.md in KB video_research).
1. **Clean, smooth, liquid glass** — airy bright bg, frosted glass panels, soft light blooms, lots of white space. Quality bar = that reel.
2. **Text is SOLID colour, never gradient.** Colourful is fine; gradient fill on text is banned.
3. **No random floating objects** — v9 floated a watch, trophy, calendar, rocket: unrelated to us = rejected. Background elements must be DESIGN elements (particles, light streaks, blur orbs, glass shards, grid dots, wave lines…), a DIFFERENT element type per video.
4. **Every video different** — v9 had same elements/mockup/design in all 7. Each video: own theme/palette (one = sky-blue FansaChat-tool theme like the reel, others different), own background animation type, own mockups/scenes. Use the clone skills (AppleMorph morphs, smooth camera, GlassUI, KineticType…).
5. **Subjective/hot words = the hero typography** — placed in the visual centre zone (eye lands there, not literal dead centre), animated with care (type-on with caret, blur-in, count-up, word swap). Hot-word colour changes per word/scene, chosen to balance with that video's background (contrast ≥3:1).
6. **Words become visuals** — e.g. "clients" = people → avatars/faces/illustrated persons appearing with motion (like the reel's face grid), "replies" → chat bubbles with count, numbers → count-ups. Every noun that can be shown, is shown.
7. Still binding from v9: bright only (no dark scenes — the reel's one dark logo-reveal scene is the exception style, ask first), real FansaChat workflow-tree mockup, word-level VO timing, camera = transitions on beats only.
