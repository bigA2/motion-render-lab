# P01–P07 v10 storyboard (draft for founder approval, 2026-10-24)
Reference: REEL_DeKoRsNgOPK_clean_liquid_glass.md. Same scripts + VO + word timings as v9; visuals rebuilt.

## Global (all 7)
- White frosted-glass card on a pale bg, soft drifting light blooms, ~70 % air. Text SOLID (ink + 2 hot colours per video), never gradient.
- 3D clay objects removed (watch, trophy, calendar, rocket, gift, money bag…). Only design elements + real UI chips + app icons where the script names the app.
- Hot words sit in the centre zone, animated: type-on + caret, blur-in, count-up, word swap, inline avatars inside the sentence.
- Nouns → visuals: people → face grid / avatars appearing; messages → chat card + count; time → clock roll; numbers → count-ups; trust → logo marquee.
- Transitions per beat: blur-in/out, input→card morph (AppleMorph), circle wipe, whip blur, camera push into a 3D laptop with the real FansaChat workflow tree.
